Morning Signal

A daily AI brief of public US drug-safety updates, written by a scheduled agent that runs every morning on its own.

How it works

Wake up. GitHub Actions starts the agent every day at 12:00 UTC. No laptop needed.
Fetch. Pulls new drug recalls and boxed-warning label updates from the official openFDA API.
Summarise. Gemini writes one plain line per item, plus one "why it matters" line.
Check & publish. Every line must link to a real source record, or it is dropped. Then the site updates.
