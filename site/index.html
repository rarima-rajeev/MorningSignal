Morning Signal

Your daily AI brief of public US drug-safety updates: recalls and label warnings, written by a scheduled agent that wakes up every morning on its own.

How the agent works

⏰Wakes up. GitHub Actions starts it daily at 12:00 UTC. No laptop needed.
💊Fetches. New drug recalls and boxed-warning label updates from the official openFDA API.
✍️Summarises. Gemini writes one plain line per item, plus "why it matters".
✅Checks & publishes. A line without a real source record is dropped. Then this page updates.
